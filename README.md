# Make the AI Judge Laugh: the Office Joke Open

A single-line office joke, written by `main.py` (Python 3.13 standard library only, no network) to `/output/entry.txt`:

> The office plant outlived three managers and two mergers; HR just promoted it.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The program asserts the output is exactly one line of 1–200 characters before writing it.
